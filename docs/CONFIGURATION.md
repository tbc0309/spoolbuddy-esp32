# 配置导入、确认和自动备份

[English](en/CONFIGURATION.md)

首次在 TF 根目录放置 spoolbuddy.json。每次启动检查此文件的修改时间；导入前
先校验完整 JSON、字段、大小及日期。成功连接 WiFi 和 Bambuddy 后，才把它
确认为有效配置并写入主板数据区。之后即使没有 TF 卡，也从板内配置启动。

板内使用独立 sb_config NVS 分区，保存两个带格式版本、递增代次和原文件
修改时间的完整记录。新记录写入另一槽并提交、读回验证；上一有效槽保留为
自动备份。某一槽损坏时选择另一有效槽，不清空配置分区。

- TF 文件日期较新且内容变化：试用新配置，连接成功后自动保存、保留旧版。
- FAT 修改时间只有两秒精度：同一日期但内容变化也会识别为更新。
- 内容相同：不反复写 Flash；较旧文件：不覆盖板内确认版本。
- TF 缺失或 JSON 无效：继续使用已确认版本。
- 新配置两分钟内未连通：恢复上一确认版本并重新连接，未确认内容不写成有效版本。
- 首次配置尚无旧版时，保留 TF 文件供修改；不会把连不通的配置当成成功配置保存。

日期指 TF 文件系统修改时间，无需在 JSON 中增加日期字段。检查发生在启动时；
从读卡器修改后插回并重启即可。无需让 TF 卡长期留在主板上。

配置中不默认加入 language。省略时跟随 Bambuddy 主设置；显式加入时优先于
后端语言。zh、zh-CN、zh-TW、zh-HK、zh-Hans、zh-Hant 等统一显示简体中文，
其他语言使用英文。启动尚未取得后端设置时默认简体中文。

timezone 可选，使用 POSIX TZ 格式，默认 CST-8（UTC+8），与界面语言独立。
例如 UTC0 表示 UTC。NTP 尚不可用时可从 Bambuddy HTTP Date 初始化 UTC，
显示时再应用本地时区；12/24 小时格式跟随后端 time_format。

本板数据区位置见 boards/esp32-p4-wifi6-touch-lcd-4.3/rev3/partitions.csv。
升级应用不擦除此分区；初次迁移分区表需要 USB 刷写。
